Why the model uses A, B and a cubic correction

The model turns pressure P and sensor current I into oxygen concentration C. It has two stages: a physics stage with coefficients A and B, then a correction applied to the physics result. This report explains why the correction is a cubic, and why a straight-line (linear) correction was not used, with the evidence from the data.

Decision. Use A, B + cubic correction. It has the lowest error on pressures the model never saw (1.93 %), puts 91 % of unseen readings on the correct concentration level (physics only: 80 %), and it always increases, so a higher current always gives a higher concentration.

Why not linear. The best straight line is C = 0.30 + 0.996·Cp, which is almost exactly “no change”. A and B already make every straight-line adjustment, so a line has nothing left to fix. The remaining error is a bend, and only a curve can remove it.

1. The final formula

Stage 1, physics (A and B fitted by Levenberg–Marquardt least squares):

Cp = 100·[1 − exp(−(I·R·T·L / 4·F·S·P)·(A/Dk + B/Db))]   with A = 1.0278, B = 0.9494

Stage 2, correction (fitted by ordinary least squares):

C = 19.281 -0.2945·Cp +0.02500·Cp² -0.0001448·Cp³

The same curve written around the middle of the data (Cp = 55.1 %) shows what it really does:

C = 54.73 +1.142·(Cp − 55.1) +0.00107·(Cp − 55.1)² -0.000145·(Cp − 55.1)³

At Cp = 55.1 % it returns 54.7 % with slope 1.14: close to “no change”, plus a small S-shaped bend. The constant 19.3 in the first form is not an amount added to every reading. It is where the curve would cross Cp = 0, far outside the data (Cp 14.4–95.8 %), and the code never uses the cubic there: outside that band it continues as a straight line.

2. The problem the correction has to fix

With A and B optimized, the physics model is unbiased on average, but the errors follow a clear pattern by concentration: 21 % comes out 4.7 % too low, 30 % comes out 3.6 % too high, and the high end is off again. This is a shape problem. A and B can only stretch the curve at each pressure; they cannot bend it.

3. Why linear does not help and cubic does

Plot the physics output against the true concentration. If the physics were perfect, every point would sit on the dashed identity line. The best straight line through the points lands on top of the identity line. The cubic follows the bend that the points actually make.

How to read this

• Linear gives nothing: it collapses to C ≈ Cp.

• Exponential (the form used for the earlier 21–40 % data) puts a second exponential on top of the physics exponential and cannot follow 21–95 %.

• Log-space is worse and does not always rise, so a higher current could give a lower concentration.

• Quadratic barely helps: one bend is not enough for the S-shape in the data.

• Cubic + pressure terms is 0.21 % better on unseen data, but needs 2 more parameters and makes the correction depend on pressure, which A and B are meant to handle. The cubic is the simplest shape that captures the bend.

7. Limits and next steps

  • The correction is empirical. It is a calibration curve chosen from the data, not derived from physics. A and B keep their physical meaning; the cubic only fixes the remaining shape. Refit it if the sensor or operating conditions change.
  • Valid range: P 56.89–595 (assumed kPa), C 21–95 % O₂. Outside it the result is an extrapolation.
  • Data quality. 30 readings were excluded as outliers (the whole “60 %” column, which reads like ~49 %, and the first three 95 % readings). The 85 % column jumps by ~30 µA from P = 144.2 and the 80 % column steps near P = 360. Checking these against the original notebook is the most likely way to reduce the error further.
  • Weakest levels: 80–85 % (the jumps above). At 95 % the physics-only model is slightly better than the cubic, because the cubic flattens near the top.
